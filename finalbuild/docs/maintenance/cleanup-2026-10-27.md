## Safe reusable local cleanup

From the repository root:

```bash
python clean.py          # preview only
python clean.py --apply  # remove the exact proposed disposable-cache list
```

The script visits only known Python/test/lint cache directories and coverage
cache files. It protects Git-tracked paths, skips environments/SDKs/native build
outputs/test-report directories/models/assets, and rejects linked or external
cleanup targets. It does not use `git clean`, delete logs, remove databases,
remove Git branches, or reset local edits. Run after tests/builds have stopped.

This workspace cleanup removed **93 cache entries / 9,114,452 bytes**. The next
preview reported **0 entries**. Developers' local cache sizes will differ.
