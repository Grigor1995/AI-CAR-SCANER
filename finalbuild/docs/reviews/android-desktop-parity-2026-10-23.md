# Android/Desktop change review — 2026-10-23

The new selection and display changes address real catalog drift. They do not
establish pixel-for-pixel UI parity or replace device acceptance testing.

## Reviewed incoming commits

Reviewed the 17 incoming main commits from `d711501` through `8734ba9`, after
fetching updates that were not in the initial local checkout. Their shared
catalog loading, Desktop-aligned navigation, heterogeneous acquisition metadata
and live-data error isolation are retained. The local parity changes were
rebased onto these commits without rewriting main.

## Implementation boundaries

- The shared snapshot is generated by `scripts/sync_offline_selector.py` from
  backend generation references while retaining curated seed records. Run it
  with `--check` to detect drift. Online exact matches take precedence.
- Engine/year ranges are reference guidance, not verified VIN fitment. Unknown
  ECUs and absent measured signals remain unknown.
- Android uses its native transport bridge. This change does not add Desktop's
  managed local backend/LLM process launcher to Android.
- Android Home and Live Data now expose analog/line widgets and EU/USA display
  units using the existing phone layout and Desktop-like color tokens. Desktop's
  multi-column workstation layout is not copied literally onto a phone.
- The APK grew from about 52 MiB to 135 MiB because all generation portraits are
  bundled. Image size optimization remains a separate opportunity.
